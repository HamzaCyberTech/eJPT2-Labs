# Search Skills - TryHackMe Lab

## Overview
Completed the Search Skills lab to strengthen proficiency in using search engines effectively for penetration testing and OSINT. The objective was to practice advanced query techniques to locate relevant information quickly and accurately.

## Tools & Techniques
- Google search operators (`site:`, `filetype:`, `intitle:`, `inurl:`)
- Query refinement and chaining
- Identification of exposed documents and directories
- Discovery of login portals and sensitive endpoints
- Leveraging cached and archived content

## Steps
1. Practiced using `site:` operator to restrict searches to specific domains.
2. Applied `filetype:` to locate publicly accessible documents.
3. Used `intitle:` and `inurl:` to identify login pages and admin panels.
4. Explored cached and archived versions of web pages for hidden information.
5. Correlated search results to build a clearer picture of the target’s exposure.

## Key Findings
- Located sensitive documents indexed by search engines.
- Identified login portals and admin panels exposed to the internet.
- Discovered cached content revealing outdated but useful information.
- Demonstrated how refined search queries can uncover overlooked data.

## Lessons Learned
- Effective search skills are critical for reconnaissance and OSINT.
- Misconfigured indexing can expose sensitive organizational data.
- Combining multiple operators increases precision and reduces noise.
- Regular audits of public search visibility are essential for security hygiene.
