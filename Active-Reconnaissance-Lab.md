# Active Reconnaissance - TryHackMe Lab

## Overview
Completed the Active Reconnaissance lab to practice direct interaction with target systems. The objective was to actively probe hosts and services to gather detailed intelligence, simulating the second phase of a penetration test.

## Tools & Techniques
- Nmap for port scanning and service enumeration
- Banner grabbing with Netcat and Telnet
- Service fingerprinting for version detection
- Vulnerability identification through open ports
- Network mapping to visualize target infrastructure

## Steps
1. Conducted Nmap scans to identify open ports and running services.
2. Performed service enumeration to detect versions and configurations.
3. Used banner grabbing to collect additional information from services.
4. Correlated findings with known vulnerabilities and misconfigurations.
5. Documented results to prepare for exploitation in later phases.

## Key Findings
- Discovered multiple open ports exposing critical services.
- Identified outdated software versions vulnerable to exploitation.
- Collected configuration details through banner grabbing.
- Built a detailed map of the target’s accessible network surface.

## Lessons Learned
- Active reconnaissance provides deeper insights but increases detection risk.
- Combining multiple tools enhances accuracy and completeness of results.
- Proper documentation of findings is essential for planning exploitation.
- Organizations must monitor for scanning activity to detect potential threats early.
