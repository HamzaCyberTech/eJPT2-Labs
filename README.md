# eJPT2 Labs & Penetration Testing Portfolio

This repository documents my hands-on labs and practical exercises completed during preparation for the **eLearnSecurity Junior Penetration Tester (eJPTv2)** certification.  
It serves as both a **study resource** and a **portfolio of penetration testing skills**, showcasing structured methodologies, tool usage, and lessons learned.

 🛠️ Skills Demonstrated
- **Reconnaissance**: Passive and active information gathering
- **Web Exploitation**: Vulnerability discovery, exploitation, and reporting
- **Network Attacks**: Enumeration, privilege escalation, and pivoting
- **Active Directory**: User enumeration, Kerberoasting, and domain exploitation
- **OSINT**: Leveraging public data sources for intelligence
- **Documentation**: Clear, professional reporting of findings



 📝 Documentation Style
Each lab file includes:
- **Overview**: Purpose and scope of the exercise
- **Tools & Techniques**: Commands, utilities, and frameworks applied
- **Steps Taken**: Methodical walkthrough of the process
- **Key Findings**: Results and vulnerabilities identified
- **Lessons Learned**: Insights for real-world penetration testing



 🎯 Purpose
This repository demonstrates:
- Practical penetration testing skills aligned with **industry standards**  
- Ability to **document findings professionally** for interviews and client reports  
- Continuous learning and preparation for **eJPTv2 and beyond** (OSCP, PNPT, etc.)



 📌 Note
