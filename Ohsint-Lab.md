# OHsint - TryHackMe Lab

## Overview
Completed the OHsint lab to practice **open-source intelligence (OSINT)** techniques. The objective was to gather information about a target using only publicly available data sources.

## Tools & Techniques
- Reverse image search (Google Images, TinEye)
- Social media analysis (Twitter, Instagram, LinkedIn)
- Metadata extraction from files and images
- Geolocation from photos and online posts
- WHOIS and DNS lookups for domain information

## Steps
1. Performed reverse image searches to identify the origin of a provided photo.
2. Analyzed social media accounts linked to the target for personal details.
3. Extracted metadata from images to reveal location and device information.
4. Conducted WHOIS lookups to gather domain registration data.
5. Correlated findings to build a profile of the target.

## Key Findings
- Identified usernames and aliases across multiple platforms.
- Discovered geolocation data embedded in images.
- Collected domain ownership details through WHOIS.
- Built a comprehensive profile using only passive OSINT methods.

## Lessons Learned
- OSINT can reveal significant personal and organizational data without direct interaction.
- Metadata in files and images is often overlooked but highly valuable.
- Cross-referencing multiple sources strengthens the accuracy of intelligence gathering.
